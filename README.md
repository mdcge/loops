# LiquidO Optical Photon Simulation (LOOPS)
An optical photon propagation simulation for LiquidO detectors. By simplifying the scope of the simulation to only support optical photons in simple LiquidO geometries (i.e. straight cylindrical fibres in basic monolithic detector volumes), big performance gains can be made over general-purpose simulation packages (such as GEANT4) all while keeping the codebase small and simple.

LOOPS is written to run on both the CPU (CLOOPS) and the GPU (GLOOPS, still pending).

## Simulation concept
Optical photon simulations are surprisingly simple in concept, with only a few effects needing to be implemented. These are:

- scattering (Rayleigh = isotropic)
- absorption
- intersections with geometry

### Generation
Photons are generated at a specified location (referred to as the "origin") with a random (isotropically distributed over all photons) direction.

The wavelength of a particular photon is sampled from the PDF generated by the scintillator material's emission spectrum. Similarly, the initial time of the photon is sampled using the scintillator's time constants.

### Scattering and absorption
Both scattering and absorption follow the same physics: given a scattering (absorption) length $\lambda_s$ ($\lambda_a$), the distance to scatter (absorption) is drawn from the exponential decay distribution

$$d(x) = e^{-\lambda_{s/a} x}$$

These lengths can depend on wavelength, so the photon wavelength is recorded in order to use the correct values.

At each scatter, the new direction is randomly sampled isotropically. This corresponds to Rayleigh scattering, which is a good approximation for media in which the light scatters on particle significantly smaller than their wavelength.

### Pipeline

For each photon, the following steps are performed:
1. Generate the photon at the specified location, with random direction and both wavelength and time obtained from the scintillator properties.
2. Sample an absorption distance $d_a$ for the photon using the absorption length at the photon's wavelength.
3. For each photon step:
   1. Sample a scattering distance $d_s$ using the corresponding scattering length.
   2. If $d_a$ < $d_s$, propagate the photon by $d_a$ then kill it.
      If $d_s$ < $d_a$, decrease $d_a$ by $d_s$, propagate the photon by $d_s$ and perform another step.
   3. ADD INTERSECTIONS.
4. Anytime a photon is absorbed or intersected, record its location and time.

## Performance
The following table shows the performance difference between four simulation models, each simulating 1000 photons from a single point source in identical media:

1. **GEANT4-nol**: GEANT4 simulation without any scintillator emission spectrum or time profile. All photons are emitted at $t=0$ with a wavelength of 450nm.
2. **GEANT4**: full GEANT4 simulation with scintillator emission spectrum and time profile.
3. **CLOOPSv1**: LOOPS simulation running on a single CPU core, without scintillator emission or time profile. All photons are emitted at $t=0$ with a wavelength of 450nm.
4. **CLOOPSv2**: LOOPS simulation running on a single CPU core, with scintillator emission spectrum and time profile.

| Model              | Time per event [s] | Speedup to slowest |
| :---               | :---:              | ---:               |
| GEANT4-nol         | 4.08               | 1.06               |
| GEANT4             | 4.34               | 1.00               |
| CLOOPSv1           | 0.09               | 48.22              |
| CLOOPSv2           | 0.08               | 54.25              |

CLOOPSv2 implemented some optimisations relative to CLOOPSv1, which is why it's a little faster even though it implements more physics.
